# Product Overview

**The Prophets Scroll** (branded as "Spiritual Hub") is an Android mobile application for spiritual growth and faith-based content.

## Core Features

- Daily devotionals in English & Kiswahili
- Personalized prayer reminders
- Faith-driven community features
- Offline access to saved content
- Category-based content (Faith, Hope, Love, Prayer, Wisdom, Family, Youth, Marriage, Finance, Worship, Healing, Leadership)

## User Journey

1. **Onboarding** - Welcome screen with app benefits
2. **Authentication** - Sign in/up with email or Google
3. **Personalization** - 3-step setup:
   - Step 1: Choose interests (minimum 3 categories)
   - Step 2: Configure daily reminders
   - Step 3: Setup complete confirmation
4. **Main App** - Access to personalized spiritual content

## Design Philosophy

- Warm, spiritual aesthetic with gold/bronze color scheme inspired by ancient scrolls
- Light theme by default (parchment/cream tones)
- Dark theme only for authentication screens
- Accessibility-first approach with proper content descriptions
